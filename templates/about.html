Overview

Kairos Automata is an automated trade execution and logging system created by Bill Dorais. TradingView sends trade signals as webhooks, which pass through a configurable Signal Router pipeline before being forwarded to Interactive Brokers for execution. Results are displayed on the dashboard along with P&L, equity curves, and execution status.

Trade Flow

TradingView Alert
  │  POST /webhook?token=... with JSON payload
  ▼
Signal Router (app.py)
  │  1. Validates webhook token
  │  2. Matches signal against enabled pipelines by strategy name
  │  3. Applies pipeline node settings (instrument, quantity, mode, broker…)
  │  4. Enforces Trading Hours node — drops signal if outside session window
  │  5. Logs trade to PostgreSQL
  ▼
IB Broker (ib_broker.py)
  │  Connects to IB Gateway via internal network
  │  Stocks: places market order directly
  │  Options: fetches chain, selects contract by target mid-price, places order
  ▼
IB Gateway Service
  │  Forwards order to Interactive Brokers servers
  ▼
Order Executed → Fill synced → Visible on dashboard

Signal Router — Pipeline Nodes

Each pipeline intercepts signals by strategy name and applies a chain of nodes before placing an order. Nodes can appear in any order.

NodeDescription
StrategyMatches the incoming strategy name. Supports wildcards, e.g. CAM_MSFT*. If omitted, the pipeline matches all signals.
InstrumentOverrides the instrument type: STK (stocks), OPT (options), FUT (futures), CRYPTO.
Options ConfigFor options signals — sets target premium (mid-price), expiry type (weekly/monthly), and side (auto/call/put).
QuantityOverrides the order size in shares, dollar amount, or % of account.
ModeRoutes to the IB paper account or live account.
BrokerSelects the execution broker (Interactive Brokers or Coinbase).
Ticker OverrideForces a specific ticker regardless of what TradingView sends.
Trading HoursDrops signals arriving outside a configured session window (e.g. 09:30–16:00 ET). No trade is logged.

Railway Services

ServiceDescription
web Runs the Flask/Gunicorn app. Handles incoming webhook signals from TradingView, maintains a PostgreSQL database of all trades, and serves the dashboard UI. Connects to IB Gateway via the internal Railway network.
ib-gateway Runs the IB Gateway application inside Docker. IBC (IB Controller) automates the login process. Exposes the IB API internally on port 4002, proxied to port 4004 via socat. Configured to trade in paper (simulation) mode.

Webhook Payload — Stocks

TradingView alerts POST the following JSON to trigger a stock trade. When a Signal Router pipeline matches, its node settings override the payload values.

{% raw %}{
  "ticker": "{{ticker}}",
  "action": "{{strategy.order.action}}",
  "sentiment": "{{strategy.market_position}}",
  "quantity": 100,
  "price": {{close}},
  "time": "{{timenow}}",
  "strategy": "CAM_MSFT_V1_5MIN",
  "interval": "{{interval}}"
}{% endraw %}

Webhook Payload — Options (pipeline-driven)

The recommended approach is to set the Instrument node to OPT and add an Options Config node in the Signal Router. The pipeline then selects the contract automatically — no options fields needed in the TradingView payload.

{% raw %}{
  "ticker": "{{ticker}}",
  "action": "{{strategy.order.action}}",
  "quantity": 1,
  "price": {{close}},
  "time": "{{timenow}}",
  "strategy": "CAM_PLTR_V6_5MIN"
}{% endraw %}

Options Config Node — How It Works

TradingView Alert → Signal Router matches pipeline
  │  Instrument node sets sec_type = OPT
  │  Options Config node sets target_premium = $1.00, expiry = weekly
  │  BUY action → Call option / SELL action → Put option (Auto mode)
  ▼
ib_broker.select_option_by_premium()
  │  1. reqSecDefOptParams → fetch full option chain (expirations + strikes)
  │  2. Resolve expiry — nearest Friday (weekly) or third Friday (monthly)
  │  3. Select ~25 strikes centred around the current underlying price
  │  4. reqTickers (bulk) → get live bid/ask for all candidates in one call
  │  5. Pick strike whose mid-price ((bid+ask)÷2) is closest to target_premium
  ▼
ib_broker.place_order(sec_type="OPT")
  │  Market order on selected contract
  ▼
Fill synced → logged to dashboard
