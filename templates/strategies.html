Camarilla Strategy
Pivot level breakout with EMA trend filter — Intraday

Core Idea

Uses Camarilla pivot levels calculated from the previous day's High, Low, and Close. H4 and L4 are the key breakout levels. EMA 8 is used as a trend filter — entries are only taken when price is aligned with momentum.

Entry Conditions

Long — Breakout above H4
  • close > dtime_h4 // closed above H4
  • open < dtime_h4 // opened below H4
  • ema8 < close // price above 8 EMA
Short — Breakdown below L4
  • close < dtime_l4 // closed below L4
  • open > dtime_l4 // opened above L4
  • ema8 > close // price below 8 EMA

All three conditions must be true on the same candle. Entry is at the open of the following candle.
