Camarilla Strategy cam_v6
RTH pivot level breakout with EMA trend filter — Intraday

Core Idea

Uses Camarilla H4/L4 levels calculated from the previous RTH session (09:30–16:00 ET) High, Low, and Close. Levels are locked at the start of each new RTH day and held flat throughout the session. EMA 8 is used as a trend filter — entries are only taken when price is aligned with momentum. Orders execute on close (process_orders_on_close = true).

Level Formula

LevelFormula
H4prevRTHClose + (prevRTHHigh − prevRTHLow) × 1.1 / 2
L4prevRTHClose − (prevRTHHigh − prevRTHLow) × 1.1 / 2

Entry Conditions

Long — Breakout above H4
  • inRTH // within 09:30–16:00 ET
  • close > h4 // closed above H4
  • open < h4 // opened below H4
  • ema8 < close // price above 8 EMA
Short — Breakdown below L4
  • inRTH // within 09:30–16:00 ET
  • close < l4 // closed below L4
  • open > l4 // opened above L4
  • ema8 > close // price below 8 EMA

All conditions must be true on the same candle. Entry executes on the close of the signal candle. No pyramiding.

Exit Rules

LongShort
Trailing stop activates +40 points profit +40 points profit
Trail distance 10 points 10 points
Hard stop loss 80 points 80 points
